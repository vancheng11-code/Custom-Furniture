# Custom-Furniture
Custom Furniture From China
One of the easiest ways to create confusion during a custom furniture order is to provide too little information.

A simple product photo isn't always enough.

Start With Dimensions

Specify the exact:

Length
Width
Height
Seat height
Thickness

For furniture used in a complete project, dimensions should also work with the surrounding space.

Define Materials

Don't simply write "wood."

Specify the preferred material, species, veneer, plywood, MDF, metal, fabric, or other components where relevant.

If a particular material is essential, put it in writing.

Describe the Finish

Color descriptions can be subjective.

Whenever possible, provide a physical sample, color code, or reference image.

For wood furniture, also specify whether you want a natural, stained, matte, gloss, or other finish.

Don't Forget Hardware

Drawers, hinges, handles, legs, slides, and other hardware can significantly affect the final product.

Include the required hardware or clearly state the performance expectations.

Add Packaging Requirements

Furniture can be damaged during transportation even when it leaves the factory in perfect condition.

Discuss carton construction, protective materials, corner protection, and other packaging requirements before production.

For buyers developing custom furniture with Chinese manufacturers, Furniture Origin can assist with sourcing and project coordination.

The more clearly you define the product, the fewer decisions the factory has to make on your behalf.
